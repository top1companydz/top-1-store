# TOP 1 — free e-commerce starter

This is the static TOP 1 storefront for free hosting.

## Included
- Responsive storefront
- 5 categories
- Product filtering and search
- Shopping cart stored in the browser
- DZD pricing
- WhatsApp ordering flow
- Mobile navigation

## Before going live
Replace the sample products, prices, product artwork, contact email, and the placeholder WhatsApp number 213000000000 in script.js.

## Free publishing
This project is designed for static hosting such as GitHub Pages or Cloudflare Pages.
